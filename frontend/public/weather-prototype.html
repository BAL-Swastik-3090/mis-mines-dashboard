🎨 3 Animation Layers
Layer 1 — Background gradient
CSS gradient, changes per weather condition. In production: replace with real Unsplash rain photo.

Layer 2 — Canvas droplets
Water droplets that grow → drip down the glass. Pure HTML5 Canvas + requestAnimationFrame. No library.

Layer 3 — CSS streaks
Falling rain/snow streaks. Pure CSS @keyframes. Lightweight, GPU-accelerated.
